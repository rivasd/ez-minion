# Escape

An in-browser puzzle game built with React, Mantine and Vite.

**Play it: https://rivasd.github.io/ez-minion/**

## Development

```sh
npm install
npm run dev
```

Game codes, answers and clues live in `.env`. Restart the dev server after editing it.
The board digits are in `src/game/config.ts`.

## Deployment

Pushing to `main` builds and deploys to GitHub Pages through
`.github/workflows/deploy.yml`.
